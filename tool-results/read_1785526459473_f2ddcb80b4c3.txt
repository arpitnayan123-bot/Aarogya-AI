     3→## Project Overview
     4→Transforming the Nexura AI (Aarogya AI) healthcare platform from a Vite + React SPA into a world-class, production-ready Next.js 16 application with:
     5→- Real AI orchestration via z-ai-web-dev-sdk (LLM + VLM)

    43→## Module Connection Logic (Orchestration)
    44→All 7 AI modules share context via the orchestrator:
    45→1. **Symptom Analyzer** → triggers Lab Report / Prediction recommendations
    46→2. **Lab Report Engine** → feeds biomarker data to Prediction Engine + Diet System
    47→3. **Diet System** → uses Lab + Symptom context for personalized plans
    48→4. **Prediction Engine** → consumes Lab + Metrics + Symptom data
    49→5. **Emotional Companion** → has access to user's health context for empathetic responses
    50→6. **Fact-check Engine** → validates AI outputs against medical databases
    51→7. **Radiology Module** → feeds findings to Symptom + Prediction engines
    52→
    53→## Safety Layer
    54→- Medical disclaimers on every AI output
    55→- Risk detection: red-flag symptoms → emergency escalation
    56→- Confidence scoring: low-confidence outputs flagged
    57→- Hallucination prevention: structured JSON schemas + validation
    58→- Doctor recommendation logic for non-routine cases
